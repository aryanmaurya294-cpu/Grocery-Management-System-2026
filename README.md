Grocery Management System

About the Project

The Grocery Management System is a web application developed using ASP.NET MVC and SQL Server. It helps manage grocery products and online orders.

Technologies Used

- ASP.NET MVC
- C#
- SQL Server
- HTML
- CSS
- JavaScript
- Bootstrap

Features

- Admin Login
- Product Management
- Shopping Cart
- Order Management
- Database Connectivity

How to Run

1. Clone or download this repository.
2. Open the solution file (".sln") in Visual Studio.
3. Configure the SQL Server connection string in "Web.config".
4. Set up the required database.
5. Run the project using Visual Studio.
